HTML и редактор кода:
старт без страха

Ты никогда не писал код? Это нормально. Сегодня мы сделаем первую веб‑страницу и поймём, как работает редактор кода.

  • Сначала — про редактор кода: без паники.
  • Потом — про HTML: как это вообще устроено.
  • В конце — украсим страницу простыми стилями.

Знакомься: редактор кода

VS Code — это не «страшная консоль», а просто продвинутый блокнот. У него есть подсказки, автодополнение и форматирование.

Что ты видишь на экране

  • Слева: панель файлов — как папки на компьютере.
  • Центр: редактор — тут ты пишешь код.
  • Внизу: статус-бар — показывает, что происходит.

Самое крутое: начни печатать <h, и VS Code сам подскажет: «ты хочешь <h1>?» 

<!-- Просто начни печатать, и подсказки сами появятся -->
<h1>Привет</h1>

Делаем первые шаги

  1. Создай папку my-first-page.
  2. Внутри создай файл index.html.
  3. Сохрани его (Ctrl+S / Cmd+S).
  4. Открой файл в браузере — просто перетащи его в окно браузера.

Это всё. Теперь у тебя есть файл, который браузер может прочитать.

Что такое HTML?

HTML — это разметка текста. Представь, что ты помечаешь текст ярлыками: «это заголовок», «это абзац», «это картинка». Браузер читает эти ярлыки и красиво отображает страницу.

Как это выглядит

<!DOCTYPE html>
<html>
  <head>
    <title>Моя первая страница</title>
  </head>
  <body>
    <h1>Привет, это моя страница!</h1>
    <p>Это абзац текста.</p>
  </body>
</html>

Каждый тег — это ярлык. Например, <h1> — самый важный заголовок, <p> — абзац.

Кто и зачем придумал HTML?

HTML придумал Тим Бернерс‑Ли в начале 1990‑х годов. Он работал в CERN и хотел, чтобы учёные могли легко обмениваться документами через интернет.

Почему HTML?

Аббревиатура HTML расшифровывается как HyperText Markup Language — «язык разметки гипертекста».

  • HyperText — значит, что можно делать ссылки и переходить между документами.
  • Markup — разметка: мы помечаем, где заголовок, где абзац, где картинка.
  • Language — язык: набор правил, которые понимает браузер.

То есть HTML — это способ сказать браузеру: «вот тут ссылка, вот тут картинка, а вот тут — список».

Самые нужные теги

Тег Что делает Пример
<h1> Главный заголовок <h1>О нас</h1>
<p> Абзац текста <p>Мы делаем классные сайты.</p>
<ul> + <li> Список <ul><li>Пункт 1</li></ul>
<a> Ссылка <a href="https://example.com">Сайт</a>
<img> Картинка <img src="cat.jpg" alt="Кот">

Практика: собираем страницу

Давай прямо сейчас соберём простую страницу. Скопируй этот код в свой index.html: 

<!DOCTYPE html>
<html>
  <head>
    <title>Моя страница</title>
  </head>
  <body>
    <h1>Добро пожаловать!</h1>
    <p>Это моя первая страница на HTML.</p>
    <ul>
      <li>Я учусь писать код</li>
      <li>Мне нравится видеть результат</li>
      <li>Скоро я сделаю что-то крутое</li>
    </ul>
  </body>
</html>

Сохрани файл, обнови страницу в браузере — и ты увидишь результат!

Украшаем страницу

Чтобы страница выглядела красивее, можно добавить стили прямо в теги. Это называется инлайн‑стили. Они удобны для быстрых тестов. 

<div style="background-color: #f5f8ff; padding: 24px; border-radius: 12px;">
  <h2>Красивый блок</h2>
  <p>Здесь можно написать что-то важное.</p>
  <button style="background-color: #5c6cd9; color: white; border: none; padding: 10px 20px; border-radius: 6px;">Нажми меня</button>
</div>

Попробуй поменять цвета и посмотреть, как меняется страница.

Мини‑задание

Сделай свой мини‑блок:

  1. Добавь заголовок и абзац.
  2. Сделай список из 3 пунктов.
  3. Вставь картинку (можно взять любую из интернета и вставить URL в src).
  4. Оформи блок с помощью инлайн‑стилей: фон, отступы, рамка, кнопка.

Когда закончишь — посмотри на результат в браузере. Ты только что сделал свою первую веб‑страницу!
